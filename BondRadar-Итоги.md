## Фильтр «Допуск»: для всех и только для квалифицированных (коммит d470449)

**Что просили.** «В настройке фильтров предусмотреть для всех, т.е не для квалифицированных».

**Где взять признак.** Биржа публикует его только в описании конкретной бумаги — `/iss/securities/{SECID}.json`, поле `ISQUALIFIEDINVESTORS` (1 — только для квалифицированных, 0 — для всех). Пачкой его нет: проверил списочный блок площадок TQCB/TQOB (47 полей), агрегатный `/iss/securities.json` (14 полей), параметры `securities=` и `iss.only=description` (игнорируются, приходит обычный список по 100 бумаг). Значит, цена вопроса — один запрос на выпуск: 3082 обращения.

**Почему робот, а не браузер.** Три тысячи запросов из каждого браузера — это и грубо, и медленно: у каждого посетителя своя копия, и всё это на глазах у человека. Поэтому завёл робота `scripts/qual.mjs` + `.github/workflows/qual.yml`: он раз в сутки (04:40 UTC) обходит TQCB и TQOB — пять потоков, пауза 150 мс, три попытки на запрос — и кладёт `public/qual.json` тем же приёмом, что рейтинги, ГИР БО и первичка. Полный обход занял около двух минут, файл 52 КБ.

**Первый прогон.** 3082 выпуска: **808 только для квалов** (26 %), 2274 для всех, без ответа — ни одного (покрытие 100 %). В файле лежат `counts`, `coverage`, `partial` и `generatedAt`: если биржа начнёт отвечать не по всем бумагам, сайт честно скажет «проверено N из M», а прогон в CI упадёт с ошибкой (данные при этом всё равно коммитятся — порог 95 %).

**Что на сайте.** В скринере новый фильтр «Допуск»: Все / Для всех (не для квалов) / Только для квалифицированных, и пометка «квал» у выпуска в списке (в подсказке сказано, что окончательно допуск определяет брокер, а не сайт). В `matches` признак `null` — «биржа не отдала» — не проходит ни один из точных вариантов: обещать «доступна всем» про непроверенную бумагу нельзя. Признак подмешивается к списку в `withQual()` (как рейтинги в `withRatings`), а в карточке и попапе по-прежнему уточняется из описания бумаги.

**Проверка в браузере.** При «Все» — 483 выпуска (как было), при «Только для квалифицированных» и рейтинге AAA — 49: ВТБСУБ*, РЖД 1Б-*, ГазпромК, СФО, ДОМСУБТ, Сбер2СУБ2R, «СинСекью_А». Это ровно те бумаги, которые и должны быть только для квалов, так что признак читается верно. Пометка «квал» видна у каждой строки выборки.

**Чего в источнике нет (и мы не выдумываем).** Правил ЦБ про флоатеры и структурные выпуски у нас нет: фильтр опирается только на биржевой признак. Решения о допуске конкретного человека сайт не принимает — это дело брокера.
