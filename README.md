# БондРадар — клон bondradar.pro

Скринер облигаций Московской биржи. React + Vite, без бэкенда, хостинг на GitHub Pages.

**Сайт:** https://yakotpoliglot-creator.github.io/bond-radar/

## Что внутри

| Раздел | Данные |
|---|---|
| Главная | Кривая доходности ОФЗ, индекс RGBI, индекс корпоратов, ключевая ставка, карта рынка «доходность × срок» |
| Скринер | 3095 выпусков (TQCB + TQOB): фильтры по доходности, типу купона, сроку, листингу, обороту + пагинация по 50 |
| Карточка выпуска | Цена, доходность, купоны, НКД, дюрация, оферты, амортизация, график купонных выплат, похожие выпуски |
| Эмитенты | 466 эмитентов, сгруппированных по коду из REGNUMBER (покрытие 2874 выпуска) |
| Подборки | 16 подборок: ОФЗ, флоатеры, валютные, замещающие, ВДО, с офертой, ежемесячный купон, с амортизацией, суборды, короткие, длинные, структурные, 1 уровень, фикс, цена < 90 %, без оферты |
| Акции | 262 акции TQBR (обыкновенные и привилегированные) с оборотами и оценкой капитализации |
| Календарь | Купоны, погашения и оферты рынка: будущая и прошлая неделя |
| Портфель / Избранное | Хранятся в localStorage браузера |

## Источник данных

Только **MOEX ISS** (`iss.moex.com`), запросы напрямую из браузера — CORS подтверждён. Бэкенда нет.

Используемые эндпоинты:
- `/engines/stock/markets/bonds/boards/TQCB/securities.json` — корпоративные облигации (3033)
- `/engines/stock/markets/bonds/boards/TQOB/securities.json` — ОФЗ (62). Пересечений с TQCB нет, списки объединяются
- `/securities/{isin}.json` — описание выпуска
- `/securities/{isin}/bondization.json` — график купонов, амортизация, оферты
- `/engines/stock/zcyc.json` — кривая доходности ОФЗ
- `/history/engines/stock/markets/index/securities/{secid}.json` — история индексов. Работают RGBI, RUCBCPNS и RUCBTRNS; базовые RUCBTR/RUCBITR историю не отдают
- `/engines/stock/markets/shares/boards/TQBR/securities.json` — акции (SECTYPE 1 — обычка, 2 — преф; J — ETF, отфильтрованы)
- `/securities.json?q=` — эмитент по ISIN

## Чего НЕ будет

Данных, которых нет в открытых источниках, на сайте нет — и не будет выдумано:

- **Финансовый анализ эмитента** (выручка, EBITDA, чистый долг, ICR) — MOEX эту отчётность не отдаёт.
- **Кредитные рейтинги** (АКРА, Эксперт РА, НКР, НРА) — MOEX рейтинги не предоставляет.
- **Первичные размещения с книгой заявок** — только ручная агрегация.
- **Push-уведомления** — нужен сервер.

Вместо этого на карточке выпуска показываются флаги риска, которые MOEX реально отдаёт: `HASDEFAULT`, `HASTECHNICALDEFAULT`, уровень листинга, Z-спред, оборот.

## Качество данных

MOEX иногда отдаёт битую доходность: у 7 выпусков `YIELDATPREVWAPRICE` превышает 500 % (максимум — 177 628 %), у 51 — отрицательная; всего помечается 26 выпусков. Такие значения показываются как «н/д» (`ytm: null`, сырое значение сохраняется в `ytmRaw`), в подборках скрываются, а в скринере есть переключатель «Скрыть аномальную доходность» (включён по умолчанию).

Ещё две честные оговорки:

- Подборка «Замещающие» собрана по маркеру «ЗО» в названии (41 выпуск) — биржа не помечает такие бумаги отдельным признаком, поэтому список неполный.
- Цены нет у 336 выпусков из 3095 — по ним не было сделок.

Проверить слой данных на живой бирже:

```bash
node scripts/verify.mjs
```

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/bond-radar/
npm run build    # сборка в dist/
```

## Деплой

Автоматический: `.github/workflows/deploy.yml` собирает проект и публикует на GitHub Pages при каждом push в `master`.

## Структура

```
src/
  api/moex.js        слой данных MOEX (нормализация, кэш, подборки)
  lib/format.js      форматирование чисел и дат
  lib/store.js       localStorage: портфель, избранное, тема
  components/
    Layout.jsx       боковое меню, переключатель темы
    ui.jsx           таблица облигаций, пагинация, KPI, панели
  pages/             страницы
  styles/theme.css   токены и компоненты (извлечены из CSS bondradar.pro)
```

## Дизайн

CSS-токены и формы компонентов извлечены из реального бандла bondradar.pro (160 КБ, 1468 правил): тёплая светлая тема `#f7f6f3`, тёплая тёмная `#131511`, шрифты Inter (текст), Lora (заголовки), JetBrains Mono (числа).
