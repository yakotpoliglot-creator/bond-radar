# BondRadar Clone

Аналог сайта bondradar.pro — скринер облигаций Московской биржи.

**Демо:** https://yakotpoliglot-creator.github.io/bond-radar/

## Функции

- 🔍 Скринер облигаций (2200+ выпусков, фильтры по YTM, типу купона, датам, уровню листинга)
- 📄 Карточка облигации (цена, YTM, НКД, дюрация, график купонных выплат)
- 🏢 Страница эмитента (все выпуски с ценами/доходностями)
- 📂 Подборки (ОФЗ, флоатеры, ВДО, замещающие, и др.)
- 📈 Акции Мосбиржи (260 шт, дивиденды, капитализация)
- 📅 Календарь событий (ближайшие купоны, погашения, оферты)
- 💼 Портфель и избранное (сохраняются в браузере)
- 🌓 Тёмная/светлая тема

## Источники данных

- **Московская биржа (MOEX ISS)** — цены, доходности, купоны (прямые fetch из браузера)
- **GitHub Actions** — раз в неделю собирает кредитные рейтинги и аналитику

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
# Результат в папке dist/
```
